# Blog Idea Generator Agent

Turn a short brief into a batch of distinct blog post ideas you can pick from. Describe the topic, the audience, and the tone, and the agent returns several ready-to-evaluate ideas — each with a working title, a one-paragraph summary, and a numbered outline you can hand straight to the draft writer.

## Capabilities

- Generate a batch of distinct blog post ideas from a short brief
- Tailor every idea to the audience and tone you specify
- Produce a working title, summary, and outline for each idea
- Skip topics you have already covered to keep the batch fresh
- Pull in brand voice context to keep ideas on-message
